# 岩手県・秋田県 市町村役場 所在地・連絡先データセット

岩手県(33市町村)・秋田県(25市町村)の**市町村役場(本庁舎)**の
郵便番号・住所・代表電話・公式サイトURLをまとめた、機械可読のオープンデータです。

## なぜ作ったか

多くの県は「県内市町村の役場所在地一覧」を公式に公開していますが、
**岩手県・秋田県には県がまとめた機械可読の一覧が見当たりません**
(給与公表のクロスリンク集はあるが、住所・電話は各市町村サイトに散在)。
同じものを探している人が使えるよう、公式サイトから収集して置いておきます。

## ファイル

| ファイル | 内容 |
|---|---|
| `iwate.csv` / `iwate.json` | 岩手県 33市町村 |
| `akita.csv` / `akita.json` | 秋田県 25市町村 |

### 列

| 列 | 説明 |
|---|---|
| `city_code` | 全国地方公共団体コード(5桁。総務省/国土数値情報N03準拠) |
| `name` | 役場名(市=「〇〇市役所」、町村=「〇〇町役場/〇〇村役場」) |
| `postal_code` | 本庁舎の郵便番号 |
| `address` | 本庁舎の住所(県名プレフィックスなし) |
| `phone` | 代表電話 |
| `official_url` | 自治体公式サイトのトップURL |
| `source_url` | 住所・電話を実際に取得した公式ページのURL |
| `verified_at` | 確認日(YYYY-MM-DD) |

## 収集方法

1. **公式URLの確定**: 各県の「市町村職員給与・定員管理の公表」クロスリンク集
   (県公式ページ)から58自治体の公式ドメインを取得。県公式からの被リンクで公式性を確認。
2. **住所・電話の取得**: 各市町村公式サイトのフッター/庁舎案内ページを決定的にパース
   (正規表現、NFKC正規化)。合併市の総合支所を誤って拾わないよう**本庁舎**を優先。
3. **検算**: 全国地方公共団体コードのマスタ(岩手33/秋田25)と過不足なく一致することを確認。
   郵便番号・電話の形式、住所に自治体名を含むことを機械チェック。
4. J-LIS全国自治体マップ検索との突合を試みたが、同サイトはbot対策で機械取得不可のため、
   公式サイト内の複数ページ間の一致で代替検証した。

いずれも **各自治体の公式サイトのみ**を情報源としています。
